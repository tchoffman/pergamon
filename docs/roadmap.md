# Roadmap

Build order from the 2026-11-16 design review. Why each item exists is in
[decisions.md](decisions.md); what "done" means is in each issue.

## Next: make what's built feel like real apps

1. [#16](https://github.com/tchoffman/pergamon/issues/16) HTTPS on the hub
2. [#17](https://github.com/tchoffman/pergamon/issues/17) One app shell: home screen, shared look, installable
3. [#18](https://github.com/tchoffman/pergamon/issues/18) Sign in with username and password; key underneath
4. [#19](https://github.com/tchoffman/pergamon/issues/19) Host moderation: hide posts, block keys

## Then: new apps, in order

5. [#20](https://github.com/tchoffman/pergamon/issues/20) Messages: end-to-end encrypted, carried between towns
6. [#24](https://github.com/tchoffman/pergamon/issues/24) Maps: offline map of the region
7. [#25](https://github.com/tchoffman/pergamon/issues/25) Entertainment pack
8. [#26](https://github.com/tchoffman/pergamon/issues/26) Local guide

## Alongside

- [#21](https://github.com/tchoffman/pergamon/issues/21) Trusted hubs, plus reviewed courier sticks (needed before Messages travel)
- [#22](https://github.com/tchoffman/pergamon/issues/22) Marketplace prices: dollars by default, trade, local unit
- [#23](https://github.com/tchoffman/pergamon/issues/23) Optional indexing per library item; keyword search for the rest
- [#27](https://github.com/tchoffman/pergamon/issues/27) USB installer: turn any laptop into a Pergamon node
- [#28](https://github.com/tchoffman/pergamon/issues/28) Small machines forward questions to a bigger node

## Earlier issues still open

#4 delegation UX, #5 food inventory PWA (install part folded into #17),
#6 reverse proxy (likely home for #16), #8 full ZIM ingestion (see #23),
#10 foraging shelf, #12 photo species ID (needs #16), #14 file transfer
between pergamons.

The first roadmap, with module ideas (shortwave, ham, Reticulum, APRS) and
library reading lists, is kept in [roadmap-early.md](roadmap-early.md).
