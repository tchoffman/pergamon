This hub isn't on the internet, so it vouches for itself with its own certificate. Tell this device to trust it once, and Pergamon works like a normal secure website: you can add it to your home screen and use the camera.

iPhone / iPad
  1. In Safari, tap Download profile, then Allow.
  2. Open Settings. Tap Profile Downloaded near the top (or General → VPN & Device Management), then Install. It will say "Not Verified"; that's expected for a hub with no internet.
  3. Go to Settings → General → About → Certificate Trust Settings and switch on {{ ca_name }}.
  4. Come back here; this page turns green.
Android
  1. Tap Download certificate.
  2. Open Settings and search for CA certificate (usually Security → More security settings → Encryption & credentials → Install a certificate → CA certificate).
  3. Tap Install anyway and pick pergamon-ca.crt from Downloads.
  4. Come back here in Chrome; this page turns green.
Mac
  1. Download the certificate and open it; it goes into Keychain Access.
  2. In Keychain Access, double-click {{ ca_name }}, open Trust, and set When using this certificate to Always Trust.
Windows
  1. Download the certificate and open it.
  2. Choose Install Certificate, then place it in Trusted Root Certification Authorities.

Firefox keeps its own list: in Firefox, use Settings → Privacy & Security → Certificates → View Certificates → Authorities → Import.
